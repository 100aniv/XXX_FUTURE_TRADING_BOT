## 📊 Objective Function (PHASE14 강화)

### Base Score
```python
base_score = PF + 0.1 * Winrate
```

### Penalties (Constraints)

#### 1. Trades Constraint (30-day 기준)
```python
if trades == 0:
    return -100.0  # Complete rejection
elif trades < 15:  # 30일 기준 최소값 상향
    penalty = (15 - trades) * 0.5
    return -penalty
elif trades > 80:  # 30일 기준 최대값
    penalty = (trades - 80) * 0.1
    score -= penalty
```

#### 2. Max Drawdown Constraint
```python
if max_dd < -15.0:
    dd_penalty = (abs(max_dd) - 15.0) * 1.5  # PHASE14: 패널티 완화 (2.0 → 1.5)
    score -= dd_penalty
```

#### 3. Winrate Constraint
```python
if winrate < 20.0:  # PHASE14: 기준 완화 (15.0 → 20.0)
    wr_penalty = (20.0 - winrate) * 0.3
    score -= wr_penalty
```

#### 4. TP Hit Incentive (신규)
```python
if tp_hit_rate > 0:
    tp_bonus = tp_hit_rate * 0.5  # TP Hit 1%당 +0.5점
    score += tp_bonus
```

### Final Score
```python
final_score = base_score - dd_penalty - wr_penalty - trades_penalty + tp_bonus
```
