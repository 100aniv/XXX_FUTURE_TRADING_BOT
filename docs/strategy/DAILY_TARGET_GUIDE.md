### 2. RR (Risk-Reward Ratio) 이해

**RR은 수익률이 아닌 "리스크 대비 보상 비율"입니다!**

```
예시: RR = 2.0
├─ 진입가: 50,000 USDT
├─ 손절가: 49,000 USDT (2% 리스크)
└─ 익절가: 52,000 USDT (4% 수익)

즉: 2% 잃을 리스크로 4% 수익을 노림
```

#### RR별 실제 수익률

| RR | 리스크 | 수익 | 승률 60% 기대값 |
|----|--------|------|----------------|
| 1.5 | 2% | 3% | 0.6×3% - 0.4×2% = 1.0% |
| 2.0 | 2% | 4% | 0.6×4% - 0.4×2% = 1.6% |
| 3.0 | 2% | 6% | 0.6×6% - 0.4×2% = 2.8% |

```
이유: 포트폴리오 분산, 리스크 관리
```

### 4. TP/익절 동적 조정

**이미 Signal Bot에서 ATR 기반으로 자동 조정됩니다!**

```python
# 변동성 높을 때 (ATR 크면)
→ 손절폭 넓어짐 (큰 ATR × 1.5)
→ 익절폭도 넓어짐 (큰 손절폭 × RR)

# 변동성 낮을 때 (ATR 작으면)
→ 손절폭 좁아짐 (작은 ATR × 1.5)
→ 익절폭도 좁아짐 (작은 손절폭 × RR)
```

**즉, 시장 상황에 따라 자동으로 조절됨!**
