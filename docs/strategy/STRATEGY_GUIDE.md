## ⚠️ 하루 10% 목표에 대해

### 현실
- **단기적으로 가능**: 운 좋으면 한 달에 몇 번
- **지속 불가능**: 매일 10%는 현실적으로 불가능
- **복리 함정**: 매일 10% = 연 100만% (불가능)

### 추천 목표
```
보수형: 하루 2-3%   → 월 60-90%   → 연 1,000-2,000%
균형형: 하루 5-7%   → 월 150-210% → 연 5,000-10,000%
공격형: 하루 7-12%  → 월 210-360% → 연 10,000-50,000%
```

이것도 **엄청난 수익**입니다!

## 🔧 미세 조정 가이드

신호 받아본 후:

### 신호가 너무 적으면
```bash
COOLDOWN_CANDLES=2    # 3 → 2
SYMBOLS에 코인 추가
REQUIRE_HTF_ALIGNED=false
```

### 신호가 너무 많으면
```bash
COOLDOWN_CANDLES=5    # 3 → 5
ENABLE_VOL_SPIKE_FILTER=true
REQUIRE_HTF_ALIGNED=true
```

### 승률이 낮으면
```bash
RR=2.0               # 1.8 → 2.0
ATR_MULT_SL=1.5      # 1.2 → 1.5
TIMEFRAME=15m        # 5m → 15m
```

### 수익이 적으면
```bash
RR=1.5               # 1.8 → 1.5
RISK_PER_TRADE=0.008 # 0.005 → 0.008
```
