# 엔진 코어 모듈 리팩토링 계획 (v1)

## 현재 문제점
1. **아키텍처 문제**
   - 앙상블 신호 처리 인터페이스 불일치
   - 모듈 간 순환 참조 존재 (SignalGenerator ↔ Engine)

2. **성능 문제**
   - 싱글 스레드 처리로 인한 지연
   - 캔들 처리 평균 120ms 소요 (목표: 50ms 이하)

3. **안정성 문제**
   - 예외 발생 시 재시작 로직 미흡
   - 24시간 이상 운영 시 메모리 누수 (약 1.2GB/일)

## 개선 방안
### 1. 인터페이스 표준화
```python
class IEngineCore(ABC):
    @abstractmethod
    def process_ensemble(self, signals: List[Signal]) -> List[Signal]:
        pass
```

### 2. 성능 개선
- 멀티프로세싱 도입 (ProcessPoolExecutor)
- 캔들 처리 파이프라인 최적화

### 3. 안정성 강화
- 핵심 루프 try-catch 블록 추가
- 메모리 프로파일링 지점 추가
