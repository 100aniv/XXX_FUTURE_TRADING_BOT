## 🔴 치명적 문제 (Critical)

### 1. 프리로드 완전 실패 ⚠️

**증상**:
```
2025-10-29 02:10:20,899 [WARNING] ⚠️ [76/100] LDOUSDT 프리로드 실패: 
2025-10-29 02:10:21,037 [WARNING] ⚠️ [77/100] CRVUSDT 프리로드 실패: 
...
2025-10-29 02:10:24,501 [INFO] ✅ 전체 심볼 프리로드 완료: 100개
```

**문제점**:
- 히스토리 로드는 성공 (✅ CRVUSDT 히스토리 로드 완료: 100개 캔들)
- 프리로드는 실패 (⚠️ CRVUSDT 프리로드 실패: )
- **에러 메시지가 빈 문자열** → 원인 파악 불가
- 성공/실패 카운트 없음 → 실제 상태 불명

**영향**:
- 거래 시작 불가
- 버퍼 초기화 실패
- 신호 생성 불가

**근본 원인 추정**:
1. 예외 처리 누락 (빈 except 블록)
2. 큐 사이즈 초과 (5000개 제한)
3. 데이터 형식 불일치
4. 메모리 부족

**해결 방안**:
```python
# ✅ 진단 코드 추가 완료 (execution/adapters/__init__.py)
- 스택 트레이스 전체 출력
- 에러 타입 명시
- 성공/실패 카운트
- 데이터 검증 추가
```

**다음 단계**:
1. 수정된 코드 실행 → 정확한 에러 확인
2. 근본 원인 파악 → 수정
3. 테스트 → 100% 성공 확인

### 2. Config 파일 관리 문제 ⚠️

**사용자 지적 사항**:
> "config 파일에서는 다른걸 삭제하는게 아니라 주석처리를 해야지  
> 나중에 또 다시 작성하게??"

**문제점**:
- 현재 방식: 불필요한 설정 삭제
- 문제: 나중에 다시 필요할 때 재작성 필요
- 결과: 시간 낭비, 설정 유실 위험

**올바른 방식**:
```yaml
# ========================================
# 심볼 선택 방식
# ========================================
symbols:
  mode: top100  # 현재 사용 중
  
  # mode: manual  # 수동 선택 (미사용, 보관)
  # manual_list:
  #   - BTCUSDT
  #   - ETHUSDT
  
  # mode: top50  # 상위 50개 (미사용, 보관)
  # top50:
  #   min_volume_24h: 10000000
```

**개선 규칙**:
1. **삭제 금지**: 모든 설정 보존
2. **주석 처리**: `#`로 비활성화
3. **명확한 표시**: `# (현재 사용)`, `# (미사용, 보관)` 주석 추가
4. **그룹화**: 관련 설정끼리 묶기
5. **백업**: 변경 전 `config_backup_YYYYMMDD.yml` 생성

### 3. WebSocket 오류 숨김 ⚠️

**증상**:
```
2025-10-29 02:10:24,501 [INFO] ✅ 전체 심볼 프리로드 완료: 100개
2025-10-29 02:10:24,502 [INFO] 🔗 WebSocket 연결 시작...
2025-10-29 02:10:24,640 [INFO] ✅ WebSocket 첫 메시지 수신!
```

**문제점**:
- 프리로드 100% 실패했지만 "완료" 메시지
- WebSocket은 정상 연결되었지만 데이터 없음
- 버퍼가 비어있어도 "시작 가능" 메시지

**영향**:
- 사용자 혼란 (성공한 것처럼 보임)
- 실제로는 거래 불가
- 디버깅 어려움

**해결 방안**:
```python
# 프리로드 성공률 체크
if success_count < len(symbols) * 0.9:  # 90% 미만 성공
    logger.error(f"❌ 프리로드 실패율 높음: {success_count}/{len(symbols)} ({success_count/len(symbols)*100:.1f}%)")
    logger.error("   거래 시작 불가. 로그 확인 후 재시작 필요.")
    sys.exit(1)
```

### 3. 플래시 크래시 감지 추가 (내일)

**구현 위치**: `execution/risk_manager.py`

```python
class FlashCrashDetector:
    def __init__(self):
        self.volatility_window = deque(maxlen=30)  # 30분
        
    def check(self, price_change_pct: float) -> bool:
        """3시그마 기준 플래시 크래시 감지"""
        if len(self.volatility_window) < 10:
            return False
        
        volatility = np.std(self.volatility_window)
        threshold = 3 * volatility
        
        return abs(price_change_pct) > threshold
```
