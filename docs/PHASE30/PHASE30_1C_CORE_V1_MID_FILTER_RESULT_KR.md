## 4. 원인 분석

### 4.1 필터 강화의 영향

**긍정적 효과**:
1. **Win Rate 소폭 개선**: 28.99% → 31.25% (+2.26%p)
   - Regime Confidence 0.2 → 0.25로 강화
   - 신뢰도 낮은 Regime 진입 차단 ↑

2. **PF 개선**: 0.67 → 0.77 (+15%)
   - 저품질 신호 일부 차단
   - 평균 손실 폭 감소

3. **Max DD 안정화**: 3.7% → 0.9%
   - 리스크 관리 개선

**부정적 효과**:
1. **거래량 과도 감소**: 138건 → 48건 (-65%)
   - **예상**: 80~100건 (1b의 60~70% 수준)
   - **실제**: 48건 (1b의 35% 수준)
   - **원인**: 3개 필터 동시 강화 (+17~25%)가 **곱셈 효과**로 작용

2. **Win Rate 개선 부족**: +2.26%p (목표 35% 대비 여전히 -3.75%p)
   - 필터 강화만으로는 근본적 품질 문제 해결 불가
   - Optional OR 시나리오 자체의 한계

### 4.2 곱셈 효과 분석

**필터 통과율 추정**:
```
min_confidence 0.2 → 0.25: 통과율 ~80% (20% 차단)
min_atr_pct 0.0015 → 0.00175: 통과율 ~85% (15% 차단)
min_volume_ratio 0.5 → 0.6: 통과율 ~70% (30% 차단)

예상 전체 통과율 = 0.80 × 0.85 × 0.70 = 47.6%
예상 거래수 = 138 × 0.476 ≈ 66건

실제 거래수 = 48건 (예상보다 27% 추가 감소)
```

**추가 감소 원인**:
- 필터들이 서로 상관관계가 있어 **독립적이지 않음**
- 특정 시장 구간(저변동성 + 낮은 거래량)에서 **3개 필터가 모두 동시에 차단**
- 연속 손실 10회 제한에 더 빨리 도달 → 쿨다운 발동

### 4.3 근본 문제

**Core V1 전략의 구조적 한계**:

1. **Regime Detection 신뢰도 한계**
   - 복합 지표(ADX+ATR+Volume+DI)에도 불구하고 신뢰도 0.25는 여전히 낮음
   - 2024년 11월 BTC 시장이 **Trend/Range 경계가 모호한 구간** 다수

2. **Optional OR 시나리오 부족**
   - 현재 8개 시나리오(Trend 3+3, Range 2)
   - Core AND가 엄격해지면서 OR 시나리오도 충분히 트리거되지 않음
   - **EMA Pullback**: Pullback이 너무 깊으면 Trend가 끝난 것으로 오판
   - **RSI Oversold/Overbought**: 극단적 구간에서만 트리거 (Regime 신뢰도와 충돌)

3. **15m Timeframe의 한계**
   - 5m보다 노이즈는 적지만, 여전히 **False Regime 전환** 발생
   - 30m 대비 신호 품질은 낮으나 거래량은 부족

4. **SL/TP 비율의 미스매치**
   - RR 1.5는 Win Rate 40% 필요 (Break-even)
   - 실제 Win Rate 31.25% → EV = 0.3125 × 1.5 - 0.6875 × 1.0 = **-0.22** (마이너스)
