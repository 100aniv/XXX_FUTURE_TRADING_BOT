## 📊 Objective Function

### Base Score
```python
base_score = PF + 0.1 * Winrate
```

### Penalties (Constraints)

#### 1. Trades Constraint
```python
if trades == 0:
    return -100.0  # Complete rejection
elif trades < 10:
    penalty = (10 - trades) * 0.5
    return -penalty
elif trades > 100:
    penalty = (trades - 100) * 0.1
    score -= penalty
```

#### 2. Max Drawdown Constraint
```python
if max_dd < -15.0:
    dd_penalty = (abs(max_dd) - 15.0) * 2.0
    score -= dd_penalty
```

#### 3. Winrate Constraint
```python
if winrate < 15.0:
    wr_penalty = (15.0 - winrate) * 0.3
    score -= wr_penalty
```

### Final Score
```python
final_score = base_score - dd_penalty - wr_penalty - trades_penalty
```
