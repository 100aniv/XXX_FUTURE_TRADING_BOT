## 🚨 4. 심각한 문제점

### 4.1 COAIUSDT -438% 손실 케이스

```
Entry: $0.9155 (SHORT)
Exit:  $4.934 (SL)
PNL:   -438.92%
```

**문제**:
- SHORT 포지션인데 가격이 **5.4배 폭등** (0.9155 → 4.934)
- SL 설정 오류 또는 SL 미작동
- 레버리지 2x 적용 시에도 과도한 손실

**의문점**:
1. SL 가격은 얼마로 설정되었나?
2. 왜 SL이 작동하지 않았나?
3. 변동성이 큰 코인을 필터링하지 않았나?

### 4.2 승률 6.65% (매우 낮음)

- 일반적인 트레이딩 시스템 승률: 40~60%
- 현재 승률은 **정상의 1/10 수준**
- **전략 신호 품질 문제** 또는 **TP/SL 설정 문제**

### 4.3 SHORT 포지션 평균 -10.31%

- LONG (-2.45%)보다 **4배 더 나쁜 성과**
- SHORT 전략 로직 검토 필요
- 또는 최근 8시간이 상승장이었을 가능성

### 4.4 TP 청산 0건

- 모든 청산이 SL/TRAILING_SL로만 발생
- **TP가 너무 멀리 설정되었거나**
- **SL이 너무 가까이 설정되었거나**
- **RR 비율 (3.00R) 재검토 필요**

## 📋 5. 개선 방향

### 5.1 긴급 수정 (CRITICAL)

1. **One-Way Mode 준수**
   - `LiveBroker.execute()`에 `positionSide="BOTH"` 추가
   - 반대 신호 발생 시 기존 포지션 청산 로직 추가
   - 테스트: 라이브 모드 스모크 테스트 필요

2. **극단적 손실 방지**
   - 최대 손실 한도 설정 (예: -50% 초과 시 강제 청산)
   - 변동성 필터 강화 (ATR 기준)
   - 고변동성 코인 블랙리스트 추가

3. **pnl_pct NULL 문제 해결**
   - 기존 NULL 데이터 재계산 스크립트 작성
   - 또는 NULL 데이터 제외하고 분석

### 5.2 전략 개선 (HIGH)

1. **TP/SL 비율 재조정**
   - 현재: RR 3.00R (TP 거리가 SL의 3배)
   - 제안: RR 1.5~2.0R로 축소 (TP 도달 가능성 향상)

2. **SHORT 전략 검토**
   - SHORT 전략의 신호 품질 분석
   - 또는 SHORT 비중 축소

3. **진입 필터 강화**
   - 승률 6.65%는 "거의 모든 신호가 나쁨"을 의미
   - 신호 생성 로직 전면 재검토
   - 또는 신뢰도 임계값 상향 (현재 75% → 85%?)

### 5.3 모니터링 개선 (MEDIUM)

1. **실시간 알림 추가**
   - 손실 -50% 초과 시 텔레그램 긴급 알림
   - 일일 손실 한도 초과 시 시스템 중지

2. **대시보드 추가**
   - 실시간 PNL 차트
   - 승률/손익비 모니터링
