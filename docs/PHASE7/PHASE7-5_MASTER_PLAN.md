### 1. Paper/Live 파리티 검증 (2일)

**검증 항목**:
- 모든 로직 동일성 (Strategy/Risk/Engine)
- 수수료 정확 반영
- SL/TP 주문 실행
- State Recovery 동작

**파일**: `execution/adapters/brokers.py`, `config.yml`

### 2. Live 소액 테스트 (3일)

**단계**:
1. API 키 설정 및 검증
2. 최소 자본 ($100)
3. 1-2개 심볼만 (BTC/ETH)
4. 레버리지 1x (안전)
5. 24시간 모니터링

**목표**:
- 주문 실행 성공률 100%
- SL/TP 정확 체결
- 승률 Paper와 ±3% 이내

**파일**: `config.yml`, `.env`

### 3. 단계적 확장 (2일)

**확장 계획**:
- 1단계: $100, 2 심볼, 3일
- 2단계: $500, 5 심볼, 1주
- 3단계: $1,000, 10 심볼, 2주
- 4단계: Full (사용자 결정)
