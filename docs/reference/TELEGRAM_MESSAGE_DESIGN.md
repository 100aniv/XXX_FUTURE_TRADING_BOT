## 🎨 디자인 원칙

### 아이콘 규칙

| 상황 | 아이콘 | 의미 |
|------|--------|------|
| **진입 신호** | 🟢/🔴 | 롱/숏 |
| **방향** | 📈/📉 | 상승/하락 |
| **TP 달성** | 🟡 | 부분 익절 |
| **TP 완료** | 🟢 | 전체 익절 |
| **손절** | 🔴⚫ | 손실 확정 |
| **가격** | 💰💵💸 | 진입/청산/PnL |
| **지표** | 📊 | 기술적 분석 |
| **팁** | 💡 | 초보자 설명 |

### 구조 (5단계)

1. **Header** - 봇 이름, 심볼, 방향 (한눈에 파악)
2. **Meta Block** - 가격, 손절, 목표가, 수량 (핵심 거래 정보)
3. **Context Block** - 시황, 근거 (왜 진입했는지)
4. **Indicator Block** - 지표 요약 (기술적 근거)
5. **Footer** - 일일 성과, 누적 PnL

### 포맷팅 규칙

- **Bold(`**`)**: 핵심 라벨
- **숫자 콤마**: 가격은 3자리마다 콤마
- **%는 소수점 2자리**: `+2.58%`
- **구분선**: `━━━━━━━━━━━━━━━` (15개)

## 📝 기존 vs 신규 비교

| 항목 | 기존 (Old) | 신규 (New) |
|------|-----------|-----------|
| **가독성** | 📄 리포트형, 텍스트 밀집 | 📱 카드형, 구조화 |
| **핵심 정보** | 중간에 흩어져 있음 | 상단에 집중 |
| **초보자 설명** | 긴 문장 10줄+ | 3줄 요약 |
| **지표 표시** | 한 줄씩 나열 | 불릿 포인트 정리 |
| **봇 구분** | 없음 | `[SCALP]` `[INTRA]` `[SWING]` |
| **구분선** | 없음 | `━━━━━━━` 사용 |
| **PnL 표시** | USDT만 | USDT + % 함께 |
