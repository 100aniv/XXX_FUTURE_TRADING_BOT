## 🎯 **원인 분석**

### **1. 승률 문제 (26.8%)**
**원인**:
- 엔트리 필터가 약함 (HTF 확인 부족)
- 세션 필터 미구현 (아시아/유럽/미국 세션 고려 X)
- 거래량 급증 필터 미흡

**영향**:
- 승률 × RR = 0.38 (목표 2.0)
- 잘못된 타이밍 진입 → SL 빈발

### **2. MDD 문제 (-470.7%)**
**원인**:
- **연속 손실 55회** (목표: ≤ 6회)
- DDL(일일 손실 한도) 미작동
- 손실 후 쿨다운 없음 → 연속 손실 누적

**영향**:
- 계좌 폭파 수준의 손실
- 복구 불가능한 낙폭

### **3. Profit Factor 문제 (0.52)**

- 총 수익: $38,048
- 총 손실: -$73,000+

   - 아시아 세션 거래 제한

3. **거래량 급증 필터**
