## 🚦 진행 단계별 기준

### **1단계: 백테스트**
```
✅ 승률 × RR ≥ 2.0
✅ MDD ≤ -20%
✅ 연속 SL ≤ 6
✅ 레짐별 기대값 모두 +
✅ Profit Factor ≥ 1.3
```
**합격 시**: 페이퍼 트레이딩 진행

### **2단계: 페이퍼 트레이딩 (4~6주)**
```
✅ 실행/슬리피지/재시작 검증
✅ 체결률 안정성 확인
✅ 주문 실행 안정화
✅ 상태 복원 테스트
```
**합격 시**: 소액 라이브 진입

### **3단계: 소액 라이브**
```
✅ 리스크 1/3로 시작
✅ 주차별 성과 검증
✅ DDL 미충족 시 유지
✅ 점진적 승급
```
**합격 시**: 정식 라이브 운영

## 🔧 튜닝 우선순위 (TUNING_VIBLE 7단계)

### **1. SL/리스크 먼저 고정**
- 1트레이드 리스크: 0.25% ~ 0.75% (최대 1.0%)
- SL 로직: ATR × k 또는 구조적 스윙

### **2. TP/트레일링 구조 최적화**
- 목표: 손익비 1:1.5 ~ 2.0
- TP 분할: TP1 (30%) + TP2 (40%) + Trail (30%)
- Trailing: ATR × k, BE 이동

### **3. 엔트리 필터 강화**
- HTF 추세 (1h/4h)
- ATR 밴드
- 세션 (런던/뉴욕)
- 이벤트 블랙아웃

### **4. 레짐 인식 & 프리셋**
- 트렌드 vs 레인지
- 저/고 변동성
- 레짐별 파라미터 분기

### **5. 실행/슬리피지 캡 튜닝**
- 페이퍼에서 체결률/슬리피지 갭 최소화
- 재시도 로직
- 부분 체결 처리

### **6. 상관/익스포저 캡**
- 동시 포지션 수: 1~3개
- 심볼 상관성 관리
- 포트폴리오 변동성 안정화

### **7. 운영 게이트 확정**
- DDL: -2% ~ -3%
- 연속 SL: 3~4 연속 시 쿨다운
- 상태 복원
