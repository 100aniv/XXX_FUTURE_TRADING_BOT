### **목표**
승률 26.3% → **40%+** 달성

### **필수 작업**

#### **1. HTF 필터 강화** (최우선)
**현재 문제:**
- 5m에서만 신호 확인
- 상위 타임프레임 무시 → 역추세 진입

**해결책:**
```yaml
filters:
  htf_confirm:
    enabled: true
    timeframes: ['15m', '1h']  # 15m, 1h 추세 일치 필수
    min_alignment: 2  # 최소 2개 타임프레임 일치
```

**예상 효과:**
- 역추세 진입 차단
- 승률 26% → 35% 예상

#### **2. 세션 필터 추가**
**현재 문제:**
- 아시아 세션(낮은 유동성) 거래
- 변동성 낮은 시간대 진입

**해결책:**
```yaml
filters:
  session:
    enabled: true
    allowed_sessions: ['europe', 'us']  # 유럽/미국만
    timezone: 'UTC'
```

**예상 효과:**
- 유동성 높은 시간대만 거래
- 승률 +3~5% 추가 개선

#### **3. 거래량 급증 필터**
**현재 문제:**
- Volume Spike 시 진입 → 급등락 피해

**해결책:**
```yaml
filters:
  volume_spike:
    enabled: true
    threshold: 2.0  # 평균 대비 2배 이상 시 진입 금지
    lookback: 20  # 20캔들 평균 기준
```

**예상 효과:**
- Flash Crash 회피
- 승률 +2~3% 추가 개선

### **1. TP 분할은 성공했지만 충분하지 않음**
- 출구 전략(TP/SL)은 완벽
- 하지만 **입구(엔트리)**가 문제
- "Good exit can't save bad entry"

- 하지만 승률을 높이지는 못함
- **나쁜 진입을 막아야 함**
